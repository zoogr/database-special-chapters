# Task Tracker API

API для управления задачами с аналитикой и визуализацией.

## Функционал

- ✅ CRUD операции для задач
- 🔐 JWT аутентификация и авторизация
- 📊 Аналитика и статистика
- 📈 Визуализация данных
- 📥 Экспорт в CSV
- 🔍 Фильтрация задач
